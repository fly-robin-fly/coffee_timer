# Coffee Timer

A button-less, battery-powered brew timer built on a round 1.28" ESP32-S3 display board. Stand it on one of its four edges to start a timer, lay it flat to switch it off.

## How it works

- **Pick a timer by orientation.** Each edge has its own duration. The screen rotates so the countdown is always upright.

  | Screen rotation | Timer |
  |---|---|
  | 0° | 6:00 |
  | 90° | 2:00 |
  | 180° | 3:00 |
  | 270° | 4:00 |

- **Countdown.** A round progress arc and an `MM:SS` label show the remaining time.
- **Finished.** When the time is up, the device beeps and the arc flashes red/blue. After 30 s it goes to sleep on its own.
- **Sleep.** Laying the device face up or face down plays a short shutdown sound and puts it into deep sleep.
- **Wake up.** Picking it up wakes it via the accelerometer's wake-on-motion interrupt. If it is still lying flat (e.g. someone bumped the table), it goes straight back to sleep without turning on the screen or beeping.
- **Battery.** The battery level is shown as a bar with a percentage, colored green → yellow → orange → red. Below 3.5 V the device shuts down.

Orientation changes are debounced (300 ms) and use hysteresis, so bumping the table or putting a cup down next to it doesn't restart a running timer.

## Hardware

- Waveshare ESP32-S3 board with 1.28" round display: GC9A01 240×240 TFT, QMI8658 IMU, battery connector with voltage divider
- Piezo beeper on GPIO 15 (pin HIGH = off)
- LiPo battery

| Function | GPIO |
|---|---|
| Battery ADC | 1 |
| Backlight | 2 |
| IMU interrupt (wake-up) | 4 |
| I²C SDA / SCL | 6 / 7 |
| Display MOSI / SCLK / CS / DC / RST | 11 / 10 / 9 / 8 / 14 |
| Beeper | 15 |

## Building and flashing

1. Install [Arduino IDE 2](https://www.arduino.cc/en/software) and the **esp32** board package by Espressif.
2. Install these libraries:
   - [LVGL](https://github.com/lvgl/lvgl) **8.3.11** (LVGL 9 is not compatible)
   - [TFT_eSPI](https://github.com/Bodmer/TFT_eSPI) 2.5.43 by Bodmer
   - [SensorLib](https://github.com/lewisxhe/SensorLib) 0.4.1 by Lewis He
3. Put an `lv_conf.h` next to the `lvgl` folder in your Arduino libraries directory. It needs at least:
   ```c
   #define LV_COLOR_DEPTH 16
   #define LV_COLOR_16_SWAP 1
   #define LV_FONT_MONTSERRAT_14 1
   ```
4. Open `ArduinoIDE_V2/main/main.ino`, select the ESP32-S3 board and its port, and upload.

The display pins are configured in `ArduinoIDE_V2/main/tft_setup.h`, so TFT_eSPI's `User_Setup.h` doesn't need to be edited.

## Configuration

All settings are in [`ArduinoIDE_V2/main/consts.h`](ArduinoIDE_V2/main/consts.h):

- `timers[]`: timer durations in seconds
- `beepDurations[]`, `beepFrequencies[]`, `beepDelays[]`: alarm sound
- `BAT_FULL_VOLTAGE`, `BAT_EMPTY_VOLTAGE`: battery range for the percentage display and shutdown
- `ORI_DEBOUNCE_DELAY`, `ORI_ENTER_THRESHOLD`, `ORI_HOLD_THRESHOLD`: orientation detection sensitivity
- Pin assignments

## Project structure

```
ArduinoIDE_V2/main/   Arduino sketch
  main.ino            timer state and main loop
  battery.*           battery voltage measurement
  beeper.*            beeper sounds
  display.*           TFT/LVGL setup, screen updates
  qmi.*               QMI8658 accelerometer
  util.*              orientation detection, debounce, deep sleep
  src/                UI generated by SquareLine Studio
SquareLine/           SquareLine Studio 1.6.1 project for the UI
```

The UI in `ArduinoIDE_V2/main/src/` is generated. To change the layout, edit the project in `SquareLine/` with SquareLine Studio and export it into that folder again.
