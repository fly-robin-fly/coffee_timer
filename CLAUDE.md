## Project

Firmware for a battery-powered, orientation-controlled coffee/brew timer on a Waveshare 1.28" round display board (ESP32-S3, GC9A01 240x240 TFT, QMI8658 IMU, piezo beeper). The device has no buttons: tilting it onto one of its four edges selects and starts a timer, laying it face up/down puts it into deep sleep.

## Build

- The sketch is `ArduinoIDE_V2/main/main.ino`, built and flashed with Arduino IDE 2 (ESP32 Arduino core). There is no build script, sketch.yaml, test suite or linter in the repo.
- Required libraries (versions noted in source): LVGL 8.3.11, TFT_eSPI 2.5.43 (Bodmer), SensorLib 0.4.1 (Lewis He, provides `SensorQMI8658.hpp`). `lv_conf.h` is not in the repo; it lives in the local Arduino libraries folder.
- `tft_setup.h` in the sketch folder is the TFT_eSPI pin/driver configuration (picked up by TFT_eSPI instead of editing its `User_Setup.h`).

## Architecture

- `main.ino` holds the timer state (`remSeconds`, `selSeconds`) and a cooperative loop: drive LVGL (`lv_timer_handler` + `lv_tick_inc(20)` with a 20 ms delay), read the accelerometer, and on a debounced orientation change pick the timer, rotate the screen and restart the countdown. At 0 seconds it beeps and flashes the arc, then deep-sleeps after 30 s.
- Modules are free-function namespaces (`Battery`, `Beeper`, `Display`, `QMI`, `Util`), each with `setup()` and/or non-blocking `cycleX()` functions driven from `loop()` using `millis()` timestamps kept in file-level globals.
- `consts.h` is the single place for pins, battery voltage limits, debounce delay, the `timers[]` durations, beep sequence and the `Orientation` enum. `Util::getTimerByOrientation` maps orientations to `timers[]` indices (not in order).
- Deep sleep / wake: `Util::deepSleep()` puts the GC9A01 to sleep, configures QMI8658 wake-on-motion on `IMU_INT_PIN` as an ext0 wakeup, and holds the beeper pin HIGH (off) through sleep via `gpio_hold_en`; `Beeper::setup()` releases that hold. Waking reboots the chip, so `setup()` runs again and immediately re-sleeps if the device is still face up/down.
- Battery: `analogReadMilliVolts` × 3 (on-board 200k/100k divider), smoothed by the `VoltageSmoother` ring buffer in `vFilter.h`, mapped linearly between `BAT_EMPTY_VOLTAGE` and `BAT_FULL_VOLTAGE`; the device sleeps when the raw voltage drops below empty.
- Screen rotation is done in hardware via `tft.setRotation()`, not LVGL.

## UI (SquareLine Studio)

- `ArduinoIDE_V2/main/src/` (`ui*.c/h`, font) is generated by SquareLine Studio 1.6.1 from the project in `SquareLine/`. Do not hand-edit it; change the UI in SquareLine and re-export. Widgets used by firmware: `ui_Arc1` (progress), `ui_Countdown` (MM:SS label), `ui_Battery` / `ui_BatteryLabel`.
- `SquareLine/backup/` holds SquareLine's automatic backup zips.
